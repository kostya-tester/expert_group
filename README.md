# Экспертная система выбора метода НК для углепластиковых деталей

## Структура проекта
- `main.py` — точка входа
- `app/` — модули приложения
- `assets/images/` — изображения дефектов из диссертации
- `build.bat` / `build.sh` — сборка EXE через PyInstaller
- `requirements.txt` — зависимости

## Сборка
### Windows
```
pip install pyinstaller pillow
build.bat
```
### Linux/Mac
```
pip install pyinstaller pillow
./build.sh
```
